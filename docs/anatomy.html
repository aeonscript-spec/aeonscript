Anatomie de l'étiquette

Le mode d'emploi
gravé dans l'ADN.

Chaque bloc AeonScript commence par une étiquette auto-descriptive. C'est ce qui permet à un décodeur, dans 200 ans, de lire le fichier sans aucune documentation externe. Survolez ou touchez chaque champ pour le décortiquer.

|AEONSCRIPT=0.1;L1=L1-4;L4=rs255-223;TYPE=text/plain;LEN=4096;ID=demo-block-1;CHECKSUM=sha256:e3b0c4…|

↑ Cliquez sur n'importe quel champ coloré

AEONSCRIPT
Version de la spécification
Indique quelle version de la grammaire AeonScript a servi à écrire ce bloc. Un décodeur futur saura quelle logique appliquer — ou refuser proprement un format qu'il ne connaît pas.

La grammaire, en 3 règles

Volontairement minimaliste — pour rester lisible pour toujours, même par une machine qu'on n'a pas encore inventée. N'importe qui peut écrire un lecteur d'étiquette en cinq lignes de code, dans n'importe quel langage.

|
Encadre l'étiquette — marque son début et sa fin.
;
Sépare les champs entre eux.
=
Relie chaque clé à sa valeur.

Conséquence : les caractères ; = | sont interdits dans les valeurs — sinon la grammaire se casserait. C'est pourquoi un type MIME comme text/plain; charset=utf-8 est refusé : le point-virgule briserait la lecture.

Combien ça pèse ?

Sur l'exemple "Bonjour" (7 octets de contenu), l'étiquette pesait 70 octets. Et cette étiquette est de taille fixe : identique que vous encodiez 7 octets ou 7 mégaoctets. Voilà pourquoi la densité est faible sur les petits messages et excellente sur les gros fichiers.

étiquette : 70 octets (90%)
"Bonjour" : 7 octets (9%)
préfixes : 1%

Pourquoi c'est LA vraie innovation

Tous les autres systèmes de stockage ADN produisent une séquence muette : pour la décoder, il faut connaître à l'avance les paramètres, conservés dans un document séparé. Si ce document est perdu, l'ADN devient illisible — même si les molécules sont parfaitement intactes.

AeonScript met le mode d'emploi dans la molécule elle-même.

L'analogie

Un colis sans étiquette : vous devez deviner le contenu et l'expéditeur. Un colis avec une étiquette complète : tout est écrit dessus. AeonScript, c'est le second.

Champs optionnels

Au-delà des six champs obligatoires, l'étiquette peut en accueillir d'autres. Elle grandit, mais reste lisible — comme les en-têtes d'un email.

ChampExempleUsage
CHECKSUMsha256:e3b0c4…Vérification d'intégrité
AUTHORSBnFProvenance — qui a archivé
LICENSECC-BY-4.0Droits sur le contenu
TIERcoldNiveau de stockage (chaud / froid / archive)
ENCRYPTaes256-gcmSchéma de chiffrement (couche L6)
COMPRESSzstdSchéma de compression (couche L6)
